# 產品客服 Agent（課程諮詢客服）— 115-1 AI Agent

## 構想
用 Coze 建立一個課程諮詢客服 Agent，回答使用者對課程的問題，並在對話中蒐集需求。

## 使用場景
- 想上課的人：詢問課程內容、時間，Agent 引用課程列表回答
- 只是閒聊或問無關的事：Agent 表明自己是課程助理，不亂答

## 預計功能（對應課程單元）
| 功能 | 單元 |
| :-- | :-- |
| 選擇模型與參數（成本 vs 精準度）| 1 |
| System Prompt、JSON 結構化輸出 | 2 |
| 記住使用者的性別、職業、年紀、想上的課 | 3、7 |
| 課程列表當知識庫（RAG）| 4 |
| 串接瀏覽器外掛讀課程網頁 | 5 |
| Chatflow 意圖判斷 | 6 |
| 前後端安全護欄（防 prompt injection、不當內容）| 8 |
| 部署到 Line、監控 token 用量 | 9 |

# ETF 定期定額行為教練（AI Agent）— 115-1 AI Agent

作者：林子翔　　平台：Coze 為主，核心部分另封裝成 skill　　狀態：單元 0 初步構想

## 一句話定位

一個隨時能開口問的理財行為教練：**在你想花錢的當下，把價格換算成「這筆錢投入 ETF 定期定額，長期會變成多少」**，並回答 ETF 的基本規格與觀念。它只做教育與試算，不預測漲跌、不推薦買賣。

## 為什麼做這個

我自己正在學習以 ETF 定期定額作為主要投資方式，也發現自己在「看到想買的東西」和「看到市場大跌」這兩個時刻最容易被情緒帶著走。這個 Agent 先是為了改善我自己的理財決策而做，再把它整理成別人也能用的版本。

課程老師提到，一般人的財商常常不太正常，這也是我認為它值得擴散給其他人的原因。

## 要解決的問題

多數人不是不懂「要投資」，而是在**買東西的當下**沒有感覺這筆錢的長期代價，也常在**市場大跌時**憑情緒停扣。這兩個時刻都需要有人即時提醒、給出具體數字，而不是丟一篇懶人包。

## 目標使用者

- 我自己，以及和我一樣剛開始接觸 ETF 定期定額的上班族與學生
- 常在社群廣告或購物平台衝動下單、想知道代價的人

## 使用場景

**場景 1：購物前換算機會成本（核心功能）**

> 使用者：我想買一支 3 萬的手機，我 25 歲，月薪 4 萬。
> Agent：（換算）這 3 萬元若以年化 5% 的假設投資 30 年，約變成 12.9 萬元；以月薪 4 萬估算，約等於工作 132 小時。你確定現在需要它嗎？

以上為示意對話。計算由程式節點執行，報酬率以保守、中性、樂觀三種假設呈現，並註明是假設、不是預測。

**場景 2：ETF 規格與觀念問答**

> 使用者：這檔 ETF 的費用率和配息頻率是什麼？
> Agent：（查詢知識庫）回答追蹤指數、費用率、配息頻率，並附上資料來源與更新日期。

使用者也可以貼 ETF 官網或證交所頁面的網址，Agent 讀取頁面後用白話解釋。

**場景 3：廣告商品溢價提醒（場景 1 的延伸輸入）**

> 使用者：FB 廣告的價格 1,290，蝦皮同款 990。
> Agent：差額 300 元；這 300 元長期投入的機會成本是……

比價本身已有成熟工具，本專案不重做，價格由使用者提供，重點放在把差額換算成機會成本。

**場景 4：無關問題**

問天氣、閒聊或要求推薦買哪一檔股票時，Agent 說明自己的服務範圍並婉拒。

## 功能規劃

| 層級 | 功能 |
| :-- | :-- |
| 必做 | ETF 規格與觀念問答（知識庫）、購物換算機會成本（程式計算）、意圖判斷與無關問題拒絕、前後端護欄 |
| 應做 | 讀取 ETF 官網或證交所網址並白話解釋、把核心換算與護欄封裝成 skill、發布到可實際使用的入口 |
| 加分 | 大跌演練：回放 2008、2020、2022 等歷史大跌，使用者每回合選照扣、加碼或停扣，最後對照一路照扣的結果 |

## 護欄原則

- 只做模擬與教育，不預測漲跌，不推薦買賣特定標的
- 報酬率只當假設區間，歷史數據標明來源與更新日期
- 防止 Prompt Injection，並過濾不當內容
- 超出範圍的問題明確告知並轉回服務範圍

## 技術選擇

| 需求 | 做法 |
| :-- | :-- |
| 平台 | Coze（chatflow 與 workflow） |
| 模型 | 先用 gpt-4o-mini，之後比較成本與精準度 |
| 複利與工時計算 | workflow 的程式碼節點（Python 或 JavaScript），避免讓 LLM 心算 |
| 知識庫 | ETF 規格卡、歷史大跌事件表，每筆標來源與更新日期 |
| 網址讀取 | browser 外掛，先用於 ETF 官網與證交所頁面 |
| 記憶 | 以變數記錄年齡、月收入、每月可投入金額等 |
| 封裝 | 核心換算腳本、ETF 規格卡與護欄規則整理成 skill，放在本 repo，方便檢視與重複使用 |
| 部署 | 以 Coze 發布成可對話的入口（網頁或通訊軟體，實際形式待定），並用 Coze 後台監控 token 用量 |

## 知識庫規劃

- **v1**：定期定額與複利公式、報酬率假設區間、3 到 5 檔常見 ETF 規格卡（追蹤指數、費用率、配息頻率）、歷史大跌事件表
- **v2**：配息與稅、交易成本
- **v3（延伸）**：債券 ETF、利率、盈透證券與 W-8BEN

資料來源以證交所公開資訊與投信公開說明書為準。
